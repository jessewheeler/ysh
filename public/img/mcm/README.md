# Man Crush Monday photos

Drop Julian Love photos in this folder — any `.jpg`, `.jpeg`, `.png`, or `.webp`. They are
cycled across every frame on `/man-crush-monday`, in filename order. One photo works; fifty
works better.

Notes:

- Portrait crops around 600×750 look best — the frames are a 4:5 aspect ratio and the image
  is center-cropped to fit.
- The file list is cached when the server boots, so restart after adding photos.
- With the folder empty, the wall falls back to `/img/tbd.jpg` rather than breaking.
